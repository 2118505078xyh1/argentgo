# 原生前端视觉规范：RPG Desktop 风格（2026-11-23）

> 用户提供 RPG Desktop 浅色/深色截图，明确要求 `native/` 前端按此风格改造。本文把截图风格转成可落地的规范，供实施代理直接对照。目标：从"能用的聊天壳"升级为"信息密度高、状态清晰、圆角卡片式"的桌面编码 agent。

## 一、整体布局（三栏）

```
┌──┬──────────────┬─────────────────────────────────────┐
│图│ 项目与会话   │ 面包屑 · 会话标题      [徽章][操作] │
│标│ ┌当前会话┐   ├─────────────────────────────────────┤
│栏│ │搜索会话│   │          用户消息（右·紫气泡）      │
│  │ 项目          │  助手消息（左·卡片）                │
│  │  · 最近会话   │  ✓ 工具行   耗时                    │
│  │  · 文档       │  ┌审批卡（黄）────────────┐        │
│  │ 已归档会话    │  │未确认工具调用  [三按钮]│        │
│  │               │  └────────────────────────┘        │
│  │ v1.6.0 · 模型 │  ┌输入框─────────────┐             │
│  └──────────────┘  │模型 · Enter 发送  [发送]│        │
└──┴──────────────┴─────────────────────────────────────┘
```

1. **最左图标栏**（~44px）：竖排导航图标（当前 chat 高亮），底部设置/状态。
2. **会话面板**（~230px）：`项目与会话` 标题；紫底「当前会话」按钮；搜索框；分组（项目 / 最近会话 / 文档 / 已归档）；底部版本+模型状态。
3. **主对话区**：顶部标题栏（面包屑 + 会话标题 + 右侧状态徽章 + 操作按钮）；中部消息流；底部输入区。

## 二、配色（紫色系，双主题）

| 语义 | 浅色 | 深色 |
|---|---|---|
| 主背景 | `#FAFAFA` | `#18181B` |
| 卡片/面板 | `#FFFFFF` | `#232327` |
| 侧栏 | `#F4F4F6` | `#1E1E22` |
| 边框 | `#E5E5EA` | `#34343A` |
| 主文字 | `#1C1C1E` | `#F2F2F5` |
| 次要文字 | `#8E8E93` | `#9A9AA2` |
| **强调紫** | `#7C5CFC` | `#9B8AFF` |
| 紫底浅 | `#F0ECFF` | `#2E2642` |
| 成功绿 | `#34A853` | `#5FCE7A` |
| 危险红 | `#D93025` | `#FF6B6B` |
| 审批黄 | `#FEF7E0`（底）`#F9AB00`（边） | `#3A2F14`（底）`#F9AB00`（边） |

与现有 `palette` 字段映射：`accent`→紫、`accentBG`→紫底浅、`accentLine`→紫半透明、`surface`→卡片、`bg`→主背景、`sidebar`→侧栏、`ok/danger/warn`→绿/红/黄。**改色值即可换肤，不改结构**。

## 三、消息卡片样式

- **用户消息**：右对齐，紫色浅底圆角气泡（浅 `#F0ECFF` / 深 `#2E2642`），圆角 12px，内边距 10-14px；附件（图片/文件）作为气泡内子卡片，带 `1/1` + `展开`。
- **助手消息**：左对齐，白/深卡片 + 细边框 + 圆角 10px；标题行（如「参考资源」）+ 内容；引用/链接用卡片内小行。
- **工具行**：紧凑单行——状态图标（✓ 成功绿 / ✗ 失败红 / ⟳ 运行中紫）+ 工具名 + 参数摘要 + 右侧耗时（如 `10ms`/`4.0s`）；可点击展开完整输出（已实现，保留）。
- **审批卡**：**醒目黄色卡片**——顶部「未确认工具调用」标题 + 黄色徽章；工具名 + 意图说明（如"把文件提交到 git，不会改内容"）；底部三按钮「始终允许 / 本会话允许 / 拒绝」（紫色主按钮为允许）；危险请求默认高亮拒绝。

## 四、顶部标题栏

- 左：面包屑（`TEMP / mpi / main`，小字次要色）+ 会话标题（粗体主色）。
- 右：状态徽章（如 `Working · 1` 黄底）+ 操作按钮（带身份 / 打开变更 / 会话状态，文字按钮圆角）。
- 高度 ~56px，底部细边框。

## 五、输入区

- 大圆角输入框（~12px），占位文字「输入任务或提问...」。
- 左下：模型名 + context 量（如 `qwen3.5-plus 4.4M context`，小字次要色）。
- 右下：`Enter 发送 · Shift+Enter 换行` 提示 + 紫色「发送」主按钮。

## 六、不变量与约束

- **只改 `native/`**，不引入新依赖（mygo 已是唯一例外），分层不变（native 经 JSON-RPC 拿数据）。
- 保留本轮已落地的能力：工具卡片可展开、消息复制/重试、三态审批+逐行 diff、偏好持久化、demo 横幅、导航诚实化、会话 CRUD 接线——**换皮不换功能**。
- i18n：en-US 主界面不得出现汉字；新文案走 `tr()` / nativeEnglish 表。
- 主题切换即时生效且持久化（prefs 已实现）。

## 七、验收

- 浅色/深色截图对照：三栏结构、紫色强调、圆角卡片、右对齐紫气泡、黄色审批卡、底部输入区。
- `gofmt -l .` 空、`go build ./native`、`go test ./native -count=1`（159+ 全绿）、i18n 门禁、archguard 11。
